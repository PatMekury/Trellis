How to read this map

The choropleth fills each pilot ward with the value of the chosen variable for the selected month. Static variables (flares, facilities, population) do not change with the month slider. The 25 proposed sensor sites are squares (PHC), triangles (school), or circles (community). Toggle the forecast layer to overlay May 2026 NO₂ projections.

All data is from the Trellis predictor table (612 ward-months × 36 columns) built in this session from open data: GRID3 v2.0 wards, Sentinel-5P NO₂ via MEEO COG, CHIRPS rainfall, NASA POWER temperature, World Bank GGFR flares, GRID3 health facilities, WorldPop population. Sources cited per ward in the popup.

DHIS2 ward forecast dashboard

Predictive view designed to sit natively in Delta SMOH's existing DHIS2 instance. Forecast is from a trained XGBoost model (xgboost_v1) with walk-forward time-series cross-validation; skill vs persistence baseline +30% on rainfall, +16% on temperature, +2% on NO₂. The model retrains nightly when new sensor and EO data arrive.

School advisory page

Mobile-first daily advisory delivered to a school administrator at every host school. Forecast-driven traffic-light alert plus an action checklist appropriate to the alert level. Below is a live preview using April 2026 forecast values.

Caregiver SMS template

Plain-text SMS sent to caregivers of children under 5 in pilot wards when the 4-week forecast issues a "likely" or "possible" alert. SMS is the lowest-common-denominator channel; no smartphone or app required.

Template

Variables filled per ward and per alert level. English template shown; Pidgin variant in Phase 1.

Primary care surge planning

For PHC supervisors: which wards in their catchment are forecasting elevated child respiratory or malaria pressure over the next 4 weeks, sorted by exposed children-under-5. Drives staffing rosters and stock allocation.
