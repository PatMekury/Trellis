# Letters of intent — generic templates

This folder contains four generic letter-of-intent templates that the project can use *if and when* it identifies real institutional candidates for each role. **No partner has been identified or contacted as of this writing.**

## Status

The four templates here describe four hypothetical engagement scenarios:

| Template file | Hypothetical role being asked of the recipient |
|---|---|
| `loi_community_partner.md` | Community-development organisation that would host community-managed sensor sites and coordinate community awareness |
| `loi_education_authority.md` | State-level education authority that would endorse school-hosted sensor sites |
| `loi_phc_authority.md` | Federal or state primary-health-care authority that would endorse PHC-hosted sensor sites |
| `loi_smoh.md` | State ministry of health that would endorse the pilot and discuss DHIS2 read access |

The original drafts named specific institutions (a particular community development group, a federal PHC agency, a particular state ministry, a state education board). Those names were aspirational, not based on prior contact, and have been removed. Each template now uses placeholders for the recipient organisation.

## When to use these templates

These templates become live when the project lead identifies a real candidate organisation for each role. Until then they are reference drafts only and **should not be sent**.

For each template, the project lead needs to:

1. Identify a specific candidate organisation
2. Verify the candidate is willing to consider the role
3. Replace the placeholders with the candidate's real name, address, and named contact
4. Update the project status preamble (incorporation status, EOI status, current contact history)
5. Have the letter reviewed by the co-PI or relevant counsel before sending

## Tone conventions (preserved from the previous drafts)

- Lead with the specific ask, not the Trellis pitch
- One clear next step per letter
- Under 200 words on the asking paragraph
- No claims of unconfirmed partnerships — no letter implies that any other institution has endorsed Trellis
- No marketing copy

## Placeholders

Every template uses these placeholders that need to be filled before sending:

- `{{date}}`
- `{{recipient_organisation}}`
- `{{recipient_address}}`
- `{{recipient_name_and_title}}`
- `{{patrick_signature}}` and current title
- `{{response_by_date}}`
- `{{trellis_status_paragraph}}` — current factual status of the project (incorporation, EOI, prior contact)

- `loi_education_authority.md` — generic education-authority template
- `loi_phc_authority.md` — generic PHC-authority template

## What this packet does NOT do

- Does not assume any prior conversation with any institution
- Does not claim Trellis has been incorporated or accepted by any funder
- Does not promise hardware, software, or data sharing on a specific timeline
- Does not commit any signatory who has not personally agreed to sign
